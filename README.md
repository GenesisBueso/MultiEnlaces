# 🌻 MultiEnlaces — Faby

Página de enlaces personales tipo "link in bio". Reúne todas mis redes sociales en un solo lugar: Instagram, TikTok, Discord, Twitch, WhatsApp, YouTube, Facebook y PayPal.

🔗 **Ver la página en vivo:**
https://genesisbueso.github.io/MultiEnlaces/

## Sobre este proyecto
Página construida en HTML y CSS puro, sin frameworks. Incluye:
- Foto de perfil con efecto de degradado
- Categorías desplegables por red social
- Diseño tipo vidrio esmerilado (glassmorphism)
- Totalmente responsiva para celular
